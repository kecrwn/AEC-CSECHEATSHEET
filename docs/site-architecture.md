# AECCHEATSHEET: Information Architecture

## Purpose

AECCHEATSHEET is a fast, static B.Tech CSE resource site for Asansol Engineering College students. It makes official routes, source classes, dates, and uncertainty visible before the reader needs to act.

## Route map

| Route | Page | Primary purpose |
|---|---|---|
| `/` | Home | Orientation, current notices, official source hierarchy, and first actions. |
| `/links` | Important Links | AEC, MAKAUT, examination, library, login-gated, payment, and student-resource routes. |
| `/resources` | Resources | Library, CSE learning stack, programming practice, NPTEL/SWAYAM, and tool resources. |
| `/curriculum` | Curriculum | Semester I–II CSE map, course-code discipline, assessment routine, and batch caution. |
| `/placements` | Placements | Published data by reporting basis, recruiter context, preparation sequence, and evidence caveats. |
| `/faculty` | Faculty & Contacts | Full public CSE faculty list, support contacts, and department directory. |
| `/social` | Socials | AEC website-linked institutional accounts and separately marked club-maintained channels. |
| `/extras` | Extras | Accommodation, fees, scholarships, conduct, anti-ragging, alumni, events, clubs, and unverified gaps. |

## Design system

The site uses a **dark technical field-manual** approach: graphite ground, dull navy evidence modules, muted cyan metadata, chalk-white reading text, and controlled lime-yellow navigation/verification cues. Large Space Grotesk-like headings establish route hierarchy, a compact monospace system signals source class and last-checked status, and restrained serif body copy supports longer explanations.

Every page begins with a chapter cover: oversized route number, page title, one operational line, a source-status strip, and a recurring slanted AEC//CSE route marker. Desktop keeps a visible left folio rail. Tablet compresses the rail to an icon/tab dock. Mobile moves it into a labelled drawer and keeps Search immediately accessible.

## Information rules

1. Official source pages appear first; community and third-party links are labelled as such.
2. Academic dates, fees, assessment rules, placements and individual roles receive a visible current-source caution.
3. Unresolved public information is stated as unavailable rather than guessed.
4. Search indexes both page-level concepts and key entities so it can route readers directly to the most relevant page or linked source.
